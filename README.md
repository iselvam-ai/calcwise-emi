# CalcWise

Free, browser-based loan calculators for Indian borrowers — **EMI**, **loan prepayment** and **loan comparison** — deployed as a static site on Vercel (<https://calcwise-emi.vercel.app>). All calculations run client-side; there is no backend, no API, no analytics and no storage of user inputs.

## Structure

| Path | Purpose |
| --- | --- |
| `index.html`, `emi-calculator.html`, `prepayment.html`, `loan-comparison.html` | Calculator pages |
| `about.html`, `contact.html`, `disclaimer.html`, `privacy.html`, `terms.html`, `404.html` | Content pages (generated by `scripts/content-pages.js`) |
| `assets/js/calcwise.js` | **Single source of truth**: config/limits, EMI & amortization maths, formatting, validation, share/print/CSV helpers |
| `assets/js/{home,emi,prepayment,comparison}.js` | Page controllers (no maths of their own) |
| `assets/css/site.css` | Compiled Tailwind + site styles (built from `src/input.css` + `tailwind.config.js`) |
| `scripts/sync-partials.js` | Writes the shared head tags, header and footer into every page; adds cache-busting `?v=` hashes; subsets the icon font |
| `tests/calc.test.js` | Calculation and validation tests (`npm test`) |
| `vercel.json` | Security headers (CSP etc.) and caching |

## Workflow

```bash
npm run release   # build CSS, then sync header/footer/head + asset hashes into all pages
npm test          # run calculation tests
```

Edit shared header/footer only in `scripts/sync-partials.js`; edit limits, defaults and example rates only in `CONFIG` in `assets/js/calcwise.js`. No runtime dependencies; the Tailwind CLI is fetched by `npx` only when rebuilding CSS.

## Validation ranges (decision record)

One range is used by every calculator. They are enforced in `CONFIG.limits` and shown in the UI from the same values.

| Input | Range | Reasoning |
| --- | --- | --- |
| Loan amount | ₹10,000 – ₹10,00,00,000 (₹10 crore) | Covers small personal / consumer loans (from ₹10,000) up to large home loans. ₹10 crore is above almost all retail home loans while still guarding against typos (e.g. an extra zero). The slider is logarithmic so the whole range is usable. |
| Interest rate | 1% – 30% p.a. | Home loans typically sit in single digits, car loans somewhat higher, and unsecured personal loans / NBFC loans can reach the high 20s. Above 30% is outside normal retail lending and is more likely an input error. 0% is rejected (it is not a reducing-balance loan). |
| Tenure | 1 – 30 years, or 1 – 360 months | 30 years is the common maximum for Indian home loans; months mode allows short consumer loans. Whole numbers only. |
| Processing fee | 0% – 10% of loan | Covers typical home-loan fees (a fraction of a percent) and higher personal-loan fees. |
| GST on processing fee | 18% (toggle) | GST on processing fees is generally 18%; users can switch it off. |
| Prepayment amount | ₹1 – outstanding principal | A prepayment cannot exceed what is owed. |
| Prepayment month | 1 – remaining EMIs | Must fall within the loan. |

Example interest rates are shown as neutral **illustrative** chips (8%, 8.5%, 9%, 10.5%, 12%) with the note "Illustrative rates — actual lender rates may vary." No lender names or "current" lender rates are shown.

## Calculation notes

* EMI = P × r × (1+r)^n ÷ ((1+r)^n − 1), r = annual rate ÷ 12 ÷ 100.
* Schedules are computed with unrounded values and displayed rounded to the nearest rupee; the final EMI is adjusted so the balance ends at exactly zero.
* Prepayments are applied after that month's EMI. "Reduce tenure" keeps the EMI; "Reduce EMI" recomputes the EMI over the remaining original tenure.
* The comparison page's effective annual rate treats fees (+GST) as reducing the amount received and solves for the rate that equates the EMIs with that amount.
